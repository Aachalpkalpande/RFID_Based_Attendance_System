# RFID_Based_Attendance_System

Radio frequency identification (RFID) is a standard term that is used to describe a system that transmits the identity (in the form of a unique 12-digit series number) of an object or person wirelessly.

[1]. The identity is transmitted using radio waves. This comes under the wide category of automatic identification technologies. RFID technology does not require contact or line of vision for communication, unlike universal UPC bar-code technology.

[2]. RFID data can be read through the human body, clothing, utensils, toys, non-metallic materials, etc. RFID tag: RFID Tag is an integrated circuit chip that has unique electronic unique code (EUC) contained in it. In a basic RFID system, tags are attached to all items that are to be stalked.
